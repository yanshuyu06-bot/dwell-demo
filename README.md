# 小屋 · 界面展示版

一个**可以单独打开的界面演示**——不用装东西、不用连后端、不用登录。

双击 `index.html` 就能跑。如果你是从链接进来的，它已经跑在 GitHub Pages 上了：

**👉 https://yanshuyu06-bot.github.io/dwell-demo/**

---

## ⚠️ 先说清楚：这是「展示版」，不是小屋本体

小屋（Dwell）是一个**私人项目**：一间只属于一个人的屋子。
屋里的助手叫**小克**，两个人一起在里面过日子——写日记、排课表、背单词、看身体数据、
放歌、共读一本书、留悄悄话。

这个仓库**只是它的一层皮**：把界面拿出来，喂上编好的假数据，好让人看看它长什么样。

|  | **展示版（这个仓库）** | 小屋本体 |
|---|---|---|
| 界面、样式、交互、动效 | ✅ **和本体完全一样** | 同一份前端代码 |
| 聊天内容 | ❌ 写死的演示对话 | 真实对话 |
| 日记 / 待办 / 夜记 / 便签墙 / 悄悄话 / 背单词 | ❌ 全部是编的示例内容 | 真实内容 |
| 后端、模型、记忆库 | ❌ **完全没有** | 一整套自建服务 |
| 能发消息、会有人回你 | ❌ 不能，输入框不会真的发出去 | 能 |
| 联网 | ❌ **一个请求都不发** | — |
| 保存你的任何东西 | ❌ 什么都不存 | — |
| 装到手机上 | ✅ 可以（是个 PWA） | 可以 |

**所以：随便点、随便翻，看不到任何真实内容，也不会留下任何痕迹。**
点坏了、点乱了，刷新一下就回到原样。

## 快速开始

```bash
# ① 最省事：双击 index.html

# ② 想要个本地网址（有些浏览器对 file:// 更严格）
python3 -m http.server 8080
# 然后打开 http://127.0.0.1:8080
```

不需要 `npm install`，不需要 Node，不需要任何配置，也不联网。

## 逛一逛：哪里值得点

打开之后**先别急着往下滚**——注意看这几处：

### 1. 锁屏（第一眼看到的那个）

时间、日期、一句随时间段变的问候（早上是 `Good morning`，深夜是 `Getting late`），
下面那个圆钮**按住往右拖**就进屋子了。

### 2. 聊天主界面（拖开锁屏之后）

演示对话是一段真实感的日常：她问一个 bug，小克先「想」（**思维链**，会自动折起来），
读了一次文件（**工具调用卡片**），然后给出带**代码块**的答案（代码块有自己的标题栏、
复制按钮、展开按钮）。后面还有**数学式**和一张**音乐卡片**。

右上角还有模型切换、搜索、容量与用量。

### 3. 左上角的菜单 → 左侧抽屉

这是整间屋子，**建议一个都点开看看**：

- **待办** —— 两个人的清单分开列，顶部有个完成度圆环
- **日历** —— 一个月历，另一个页签是课表
- **购物** —— 他只负责挑和整理，钱由人确认（这一页的文案很能说明这个项目的态度）
- **日记** —— 六个子栏目：情绪与关系档案、我的日记、最喜欢的话、便签墙、夜记、悄悄话
- **照片与回忆** —— 一张照片配当时的一句话
- **共读** —— 不必上传整本书，读到想聊的地方再贴进来
- **背单词** —— 今天过了几个词、累计多少分、连续几天、词书统计
- **健康** —— 身体数据和一颗番茄钟
- **卡片** —— 助手写的小作品

### 4. 一些容易错过的小东西

- **干活时那行「动作词」**：不是在转圈，是在写它此刻在做什么
- **那只小兽**：会在空闲、思考、打字、高兴、犯困、睡着、蹦跳之间切换，每只都是独立的一段动画
- **液态玻璃那套皮**：气泡、弹层、按钮的质感
- **`?kb=1`**：网址后面加这个，会浮出一层诊断信息（键盘高度、留白、贴底状态）——
  这是给手机端调试用的，也是这个项目的一部分

## 演示模式是怎么做的

`index.html` 顶部有一段被注释标出来的 **「演示模式」**。它做一件事：
把 `window.fetch` 拦下来，凡是 `api/…` 的请求，**直接用写死的演示数据回答**，
一个字节都不会发到网络上。

数据一律**写死、不用随机数**——这样每次打开、每张截图都一模一样，方便对照。

想接自己的后端？**把那一整段 IIFE 删掉即可**，其余代码一个字不用动，
所有请求就会照常发到同源的 `api/…`。

> 原始版本里有一份「放行名单」（让部分接口真的去请求后端）。
> 生成展示版时**整块删掉了**，就是为了保证这里绝不外发请求。

## 隐私

这个展示版**不采集、不存储、不上传任何东西**：

- 不发出任何外部请求（`fetch` 在演示模式里就被拦下了）
- 不使用 Cookie、不发埋点、没有统计
- 不保存你输入的内容（其实也发不出去）
- 仓库里**没有**后端代码、部署脚本、服务器地址、密钥或任何真实用户数据

页面上如果看到一些人名或称呼，那都是**写死的演示文案**。

## 关于里面的美术素材

`pet/` 目录下那 7 只小兽的 SVG 是**这个仓库自己画的原创占位素材**。

小屋本体用的是一套第三方卡通素材（授权 GNU AGPL-3.0）。
私有仓库里内部使用没问题，但**公开仓库里会发生授权冲突**——
AGPL 是会传染的强 copyleft，一旦随公开仓库分发，整份前端代码都会被它绑住。
所以展示版把这些素材换成了自制版本，文件名一个都没改，
页面代码因此一个字都不用动。细节见 `pet/SOURCE.md`。

## 已知的局限

这些不是 bug，是「没有后端」的必然结果：

- **发消息不会有回应** —— 输入框能打字、能发出去，但那边没有人
- **有些页面偏空** —— 照片、共读、卡片、梦境这些栏目本来就是空的
- **网页通知订阅不了** —— 需要后端配合，静态版做不到
- **数据不会保存** —— 刷新之后一切都回到初始状态
- **数学式**是按普通文字画的，不是完整的公式排版
